# Monthly Trial Balance

Odoo 17 Enterprise add-on that adds a monthly trial balance accounting report.

## Features
- Monthly rows within the selected date range
- Year and Month columns
- Initial balance, Debit, Credit, Ending balance
- Foreign currency columns
- Analytic account filter
- Multi-company selector
- Accessible from Accounting > Reporting

## Notes
- Monthly total rows show foreign-currency totals only when the month collapses to a single foreign currency; otherwise they stay blank to avoid mixing currencies.
- Child rows are grouped by account and currency for correctness.

## Installation
1. Put the module in your custom addons path.
2. Update Apps List.
3. Install **Monthly Trial Balance**.
