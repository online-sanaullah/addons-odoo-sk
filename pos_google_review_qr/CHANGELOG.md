# Changelog

## 17.0.1.1.0

- Fixed the QR image failing to load in the PoS receipt preview and browser
  print dialog.
- Replaced the `/report/barcode` image request with a self-contained PNG
  generated by Odoo's bundled ZXing encoder.
- Cached the generated PNG per PoS configuration and review URL.
- Preserved a compact 200-pixel printed size while generating the source at
  256 pixels for improved print quality.
- Updated the administrator, technical, testing, and troubleshooting
  documentation.

## 17.0.1.0.0

- Added a Google review QR setting per PoS configuration.
- Added independent review link, receipt heading, and message fields.
- Added secure Google URL validation.
- Added the QR to receipt previews, prints, and reprints.
- Added configuration to the PoS form and the standard PoS Settings page.
- Added user, administrator, technical, testing, and troubleshooting
  documentation.
