PoS Google Review QR Receipt

Turn every receipt into a simple invitation to review the correct shop

Configure a Google Maps or Google Business Profile review link on each Point of Sale. The module prints a scannable QR code, a heading, and a customizable message on the customer receipt.

Key features

  • Independent review link for every Point of Sale
  • Custom receipt heading and instruction
  • Receipt preview, print, and reprint support
  • Secure Google URL validation
  • No Google API key or external QR service
  • Compatible with multi-shop deployments

Configuration

  1. Open Point of Sale > Configuration > Settings.
  2. Select the required shop.
  3. Open the Bills & Receipts section.
  4. Enable Google Review QR Code.
  5. Paste the shop's Google “Ask for reviews” link.
  6. Optionally change the receipt heading and message.
  7. Save and reload any PoS screen that is already open.

Use the right Google link

The recommended destination is the Ask for reviews link from the shop's Google Business Profile. It opens the review flow with the correct location selected.

Link type Customer experience
Google Ask for reviews link Opens the direct review flow for the configured shop.
General Google Maps shop link Opens the listing; the customer chooses Write a review.

Designed for multi-shop use

Every PoS configuration has independent settings, so each receipt directs customers to the correct physical location.

PoS configuration Configured destination
Shop A Shop A Google Business Profile
Shop B Shop B Google Business Profile

Testing checklist

  1. Reload the PoS after saving the configuration.
  2. Print or reprint a receipt.
  3. Scan the QR with a phone.
  4. Confirm that the correct shop and review flow open.
  5. Test a physical receipt before production use.

Troubleshooting

  • If the QR is missing, confirm the feature is enabled for the correct PoS and reload the PoS frontend.
  • If Maps opens without the review form, use the Google Business Profile Ask for reviews link instead of a general listing link.
  • If a physical QR is difficult to scan, check printer scaling, resolution, and print-head condition.

Detailed user, administrator, technical, and troubleshooting guides are included in the module's docs directory.
